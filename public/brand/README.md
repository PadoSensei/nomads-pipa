# Brand Assets Directory

This directory is the designated location for official Nomads Pipa brand artwork and vector assets.

## Status

> **Notice:** The official Nomads Pipa brand assets (wordmark, circular badge, app icon, and favicon) have **not yet been supplied** to the repository.
> Per project guidelines, no synthesized, approximate, or placeholder logos or SVG assets should be created here. Assets will be added once official vector files are provided.

## Expected Asset Structure

When supplied by the design team, assets should be organized into this directory following this naming convention:

- `wordmark-ocean.svg` — Primary Nomads Pipa wordmark in Ocean Green (`#073F3B`) for light/sand backgrounds.
- `wordmark-white.svg` — Nomads Pipa wordmark in pure white (`#FFFFFF`) for dark backgrounds or photo overlays with scrims.
- `badge-circular.svg` — Official circular brand badge featuring the Wi-Fi/signal arcs, "NOMADS PIPA" lettering, and palm tree silhouette on deep green circle background.
- `app-icon.png` — High-resolution mobile application icon derived from the circular badge.
- `favicon.ico` / `favicon.svg` — Official browser favicon.

## Usage Guidelines

- Do not redraw, re-font, or synthesize replacement artwork.
- Use supplied assets as-is without altering artwork geometry or proportions.
- Maintain clear space around the wordmark equal to or greater than the height of the letter "N".
- Over photos, use the white wordmark with a dark gradient scrim (`from-black/40 to-transparent`) for contrast.
